# db0

**Keep `AGENTS.md` updated with project**

Lightweight, zero-dependency SQL connector library for JavaScript/TypeScript. Provides a unified interface over diverse SQL backends (SQLite, PostgreSQL, MySQL, LibSQL, Cloudflare D1, PGLite).

## Architecture

```
src/
├── index.ts              # Public exports
├── types.ts              # Core types: Connector, Database, Statement, SQLDialect
├── database.ts           # createDatabase() factory — wraps Connector into Database
├── template.ts           # SQL tagged template literal parser (sql`...`)
├── _connectors.ts        # Auto-generated connector registry (do not edit manually)
├── connectors/           # One file per backend (17 total)
│   ├── _internal/        # Shared helpers (BoundableStatement, cloudflare utils)
│   ├── libsql/           # LibSQL variants (core, node, http, web)
│   └── *.ts              # better-sqlite3, bun-sqlite, mysql2, postgresql, etc.
└── integrations/
    ├── drizzle/           # Drizzle ORM adapter (sqlite, postgres, mysql dialects)
    └── kysely/            # Kysely query builder adapter (auto-detects dialect)
```

## Core API

- **`Connector<T>`** — interface each backend implements: `exec()`, `prepare()`, `getInstance()`, `dispose?()`
- **`createDatabase(connector)`** — wraps a connector with disposal tracking, dialect detection, and `sql` template method
- **`db.sql\`SELECT * FROM ${table} WHERE id = ${id}\``** — tagged template with auto-parameterization
- **`db.prepare(sql)`** → `Statement` with `.all()`, `.run()`, `.get()`, `.bind()`

## Connectors

Each connector lazily initializes its underlying client and returns a `Connector` object. SQLite variants are sync-wrapped; MySQL/PostgreSQL use async pools. Connector names and aliases are registered in `_connectors.ts` (auto-generated by `scripts/gen-connectors.ts`).

Package manager: **pnpm**. Build tool: **obuild**. Typecheck: **tsgo**.

## Testing

Tests live in `test/connectors/`. A shared `testConnector()` helper (`test/connectors/_tests.ts`) runs a standard suite (create, insert, select, dispose) against any connector. Each connector test file is minimal — just calls `testConnector()` with the right setup.

## Key Patterns

- **Zero runtime deps** — all backend drivers are optional peer dependencies
- **Modular exports** — `db0/connectors/*`, `db0/integrations/drizzle`, `db0/integrations/kysely`
- **Dialect-aware** — adjusts SQL behavior (e.g., `RETURNING` support) per `SQLDialect`
- **`BoundableStatement`** base class — shared bind/execute logic in `_internal/statement.ts`
- **AsyncDisposable** — `await using db = createDatabase(...)` is supported
